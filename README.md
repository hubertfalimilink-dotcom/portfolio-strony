# Portfolio — strony dla małych firm

Trzy w pełni klikalne projekty demonstracyjne. Wszystkie firmy są **fikcyjne**,
stworzone wyłącznie po to, żeby pokazać zakres pracy.

| Demo | Co pokazuje |
|---|---|
| [`restauracja/`](restauracja/) | Wizytówka: menu, godziny liczone na żywo, rezerwacja stolika, mapa |
| [`hydraulik/`](hydraulik/) | Strona sprzedażowa: klik-i-dzwoń, cennik, zgłoszenie usterki, FAQ |
| [`rezerwacje/`](rezerwacje/) | Aplikacja: kalendarz wolnych terminów bez kolizji + panel właściciela |

Czysty HTML/CSS/JS, bez frameworków i bez zależności — strona ładuje się
natychmiast i kosztuje 0 zł miesięcznie za hosting.

Sprawdzone na szerokości 375 px: zero poziomego przewijania, wszystkie cele
dotykowe ≥ 40 px, pola formularzy 16 px (inaczej iOS Safari sam przybliża stronę).
